# FreeBSD 14.5-RELEASE 自述文件

## 摘要

本文档简要介绍 FreeBSD 14.5-RELEASE。内容包括如何获取 FreeBSD、联系 FreeBSD 项目的各种途径，以及其他信息来源的指引。

## 引言

本发行版是 FreeBSD 14.5-RELEASE 的正式发行版，也是 `14-STABLE` 分支上的最新节点。

## 关于 FreeBSD

FreeBSD 是基于 4.4 BSD Lite2 衍生的开源操作系统，可运行于 64 位 x86 架构 PC 硬件（amd64）、32 位 x86 架构 PC 硬件（i386）、64 位 Arm ARMv8-A AArch64 系统（aarch64）、32 位 Arm ARMv6/7 系统（armv6/7）、PowerPC 系统（powerpc、powerpc64）以及 RISC-V 系统（riscv64）。

FreeBSD 兼容多种外设和配置，可用于软件开发、游戏、互联网服务提供等各类用途。

本版本 FreeBSD 包含运行此类系统所需的全部内容，包括内核和基本发行版中所有实用工具的完整源代码。安装源代码发行版后，只需一条命令即可从零开始重新编译整个系统，非常适合学生、研究人员，以及单纯想弄清系统运作原理的用户。

FreeBSD 还提供大量第三方移植软件（即 Ports），便于获取和安装你喜爱的各类经典 UNIX 实用工具。每个 Port 由一组脚本组成，只需一条命令即可获取、配置、编译并安装相应软件。超过 37,000 个 Port，涵盖编辑器、编程语言、图形应用等，使 FreeBSD 成为功能强大且全面的操作环境，远超许多商业 UNIX 版本所提供的内容。多数 Port 还提供预编译的软件包，可通过 [pkg(8)](https://man.freebsd.org/cgi/man.cgi?query=pkg&sektion=8&format=html) 实用工具快速安装。

## 目标受众

本版本 FreeBSD 适合所有用户。经过测试和质量保证阶段，确保了最高的可靠性和稳定性。

## 获取 FreeBSD

获取 FreeBSD 的方式多种多样，最便捷的方式是下载发行版镜像。近期发行版镜像的链接可在 FreeBSD 网站的[下载页面](https://www.freebsd.org/where/)找到。该页面包含各类可用镜像的说明，以及获取 FreeBSD 副本的其他方式。

## 联系 FreeBSD 项目

### 电子邮件和邮件列表

一般性问题或技术支持请求，请发送至 <freebsd-questions@FreeBSD.org>。

如果你跟踪 `14-STABLE` 分支：必须订阅 <freebsd-stable@FreeBSD.org>，以及时了解可能影响你使用和维护系统的开发动态与变更。

FreeBSD 项目主要由志愿者推动，始终欢迎愿意出力的帮手——想要实现的改进远多于现有时间所能完成的数量。如需就技术事务联系开发者，或愿意提供帮助，请发送至 <freebsd-hackers@FreeBSD.org>。

上述邮件列表的通信量可能相当大。如果你的邮件访问速度较慢或费用较高，或者只关注重大公告，可以改为订阅 <freebsd-announce@FreeBSD.org>。

任何希望加入的人都可以订阅全部公开邮件列表。公开的列表超过一百个；<https://lists.freebsd.org/> 列出了所有列表，并提供浏览存档、订阅和退订的相关信息。

### 提交问题报告

建议、缺陷报告和代码贡献始终受到重视。发现任何问题请勿犹豫，尽管报告。附带修复的缺陷报告自然更受欢迎。

在具备互联网连接的机器上，提交缺陷报告的首选方式是使用 [Bugzilla 缺陷跟踪系统](https://bugs.freebsd.org)。以此方式提交的问题报告（PR）会被归档并跟踪其进展；FreeBSD 开发者会尽力尽快响应所有报告的缺陷。FreeBSD 网站提供[所有活跃 PR 的列表](https://bugs.freebsd.org/search/)；借助该列表可以了解其他用户遇到了哪些潜在问题。

更多信息请参阅 FreeBSD 网站上的[《编写 FreeBSD 问题报告》](https://docs.freebsd.org/en/articles/problem-reports/)，其中包含许多关于编写和提交有效问题报告的实用建议。

## 延伸阅读

关于 FreeBSD 的信息来源众多；部分随本发行版附带，部分可在线获取或以印刷版本形式获得。

### 发行文档

另有若干文件提供关于本发行版的更具体信息。这些文件以多种格式提供。多数发行版会同时包含 ASCII 文本（**.TXT**）和 HTML（**.HTM**）版本。部分发行版还可能包含其他格式，例如便携文档格式（**.PDF**）。

* **README.TXT**：本文件，提供 FreeBSD 的概览信息以及获取发行版的简要说明。
* **RELNOTES.TXT**：发行说明，展示 FreeBSD 14.5-RELEASE 相对于上一版本（FreeBSD 14.4-RELEASE）的新增内容和变更。
* **HARDWARE.TXT**：硬件兼容列表，列出经测试确认可与 FreeBSD 配合工作的设备。
* **ERRATA.TXT**：发行勘误。发行之后的最新信息会记录在此文件中，该文件主要适用于发行版（而非快照）。安装 FreeBSD 发行版前务必查阅此文件，因为它包含自发行版制作以来已发现并修复问题的最新信息。

安装过程中，可通过文档菜单查阅这些文档。系统安装完成后，可重新运行 [bsdinstall(8)](https://man.freebsd.org/cgi/man.cgi?query=bsdinstall&sektion=8&format=html) 实用工具再次进入该菜单。

> **注意**：要了解任何最新消息或发行后问题，在安装任何发行版之前阅读其勘误至关重要。随各发行版附带的勘误文件（很可能就放在本文件旁边）按定义已过时，但互联网上保留有持续更新的副本，应将其视为本发行版的当前勘误。这些勘误副本位于 [https://www.FreeBSD.org/releases](https://www.FreeBSD.org/releases)（以及任何保持该位置最新镜像的站点）。

### 手册页

与几乎所有 UNIX 类操作系统一样，FreeBSD 附带一套手册页，可[在线](https://man.freebsd.org/)查阅，或使用 [man(1)](https://man.freebsd.org/cgi/man.cgi?query=man&sektion=1&format=html) 命令查阅。

总体而言，这些手册页提供 FreeBSD 用户可用的各类命令和 API 的信息。

部分手册页专门介绍特定主题。典型示例包括 [tuning(7)](https://man.freebsd.org/cgi/man.cgi?query=tuning&sektion=7&format=html)（性能调优指南）、[security(7)](https://man.freebsd.org/cgi/man.cgi?query=security&sektion=7&format=html)（FreeBSD 安全简介）和 [style(9)](https://man.freebsd.org/cgi/man.cgi?query=style&sektion=9&format=html)（内核编码风格指南）。

### 书籍和文章

FreeBSD 项目维护的文档包括非常实用的 *FreeBSD Handbook*，其中包含安装和升级操作系统的详细指南；还有 *FreeBSD FAQ*（常见问题解答）。[手册](https://docs.freebsd.org/en/books/handbook/)与 [FAQ](https://docs.freebsd.org/en/books/faq/) 在[文档门户](https://docs.freebsd.org/)和镜像站点在线提供。

项目维护的其他书籍和文章更为专业化——主题广泛，从有效使用邮件列表、FreeBSD 与其他操作系统的双系统启动，到新提交者指南等，均有涵盖。与手册和 FAQ 一样，这些文档位于文档门户、镜像站点和 **doc** 仓库中。

如需 HTML 和 PDF 格式的离线文档：可安装特定语言的软件包，例如 `misc/freebsd-doc-en`（`-en` 表示英文），或多语言软件包 `misc/freebsd-doc-all`。也可以使用 **doc** 仓库的副本从源代码构建并安装。

关于 FreeBSD 的其他书籍和文档列表，可在 FreeBSD 手册的[参考文献](https://docs.freebsd.org/en/books/handbook/bibliography/)中找到。由于 FreeBSD 深植于 UNIX 传统，许多为 UNIX 系统撰写的文章和书籍同样适用，其中部分也列于参考文献中。
